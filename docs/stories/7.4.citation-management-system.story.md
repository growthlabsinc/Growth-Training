```swift
struct MedicalCitation: Identifiable, Codable, Hashable {
    let authors: [String]        // Array format
```

**Key Differences Between Models**:

- MedicalCitation: year is Int, authors is [String] array, has pmid field

### Epic 7 Technical Requirements

[Source: docs/prd/epic-7-learning-center-content-v2.md#story-7-4]

The Epic specifies a **ScientificCitation** struct with these additional requirements:

```swift
struct ScientificCitation: Codable {
    let id: String
    let authors: [String]
    let year: Int
    let title: String
    let journal: String
    let volume: Int?              // Int, not String
    let issue: Int?               // NEW: Issue number

    let url: String?

}

    case journalArticle
    case book
    case bookChapter
    case report
    case thesis
    case conference
```

### Implementation Strategy

**Decision Point**: The Epic specifies `ScientificCitation`, but the app already has `Citation` integrated with `EducationalResource` and UI components.

**Recommended Approach**:
1. **Enhance existing Citation model** rather than create ScientificCitation to avoid duplication
2. Add missing fields: `pmid`, `issue`, `accessDate`, `citationType`
3. Convert types where needed: `year` remains String for flexibility, `volume` remains String (common: "109(2)")
4. Create CitationService for DOI/PMID resolution and validation
5. Add export functionality (BibTeX, RIS)
6. Update EducationalResource integration if needed

**Alternative Approach** (if breaking changes not acceptable):
1. Create new ScientificCitation model alongside Citation
2. Add migration logic to convert between formats
3. Update EducationalResource to use ScientificCitation
4. Deprecate old Citation model

**Field Mappings for Citation Model**:
- `authors` array → Convert to comma-separated string or keep as array
- `year` int → Convert to String or Int based on model choice
- `pubmed_id` → Maps to `pmid` field
- `doi` → Extract actual DOI from text like "Available via PMC"
- `research_type` → Could map to `citationType` enum
