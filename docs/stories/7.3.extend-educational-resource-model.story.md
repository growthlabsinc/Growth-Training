### Citation Model Specification

**From Epic 7 Requirements**:

```swift
struct Citation: Codable, Identifiable, Hashable {
    let id: String
    let authors: String // e.g., "Smith, J., & Jones, A."
    let year: String
    let title: String
    let journal: String // e.g., "Journal of PE Research"
    let volume: String? // Optional: "12"
    let pages: String? // Optional: "45-67"
    let doi: String? // Optional: "10.1234/example"
    let url: String? // Optional: "https://..."
}
```

**Firestore Field Mapping** (CodingKeys required):
- `authors` → "authors"
- `year` → "year"
- `title` → "title"
- `journal` → "journal"
- `volume` → "volume"
- `pages` → "pages"
- `doi` → "doi"
- `url` → "url"

**APA 7th Edition Formatting** (computed property):
```swift
var formattedAPA: String {
    var formatted = "\(authors). (\(year)). \(title). *\(journal)*"
    if let vol = volume, !vol.isEmpty {
        formatted += ", *\(vol)*"
        if let pgs = pages, !pgs.isEmpty {
            formatted += ", \(pgs)"
        }
    }
    if let doi = doi, !doi.isEmpty {
        formatted += ". https://doi.org/\(doi)"
    } else if let url = url, !url.isEmpty {
        formatted += ". \(url)"
    }
    return formatted
}
```
