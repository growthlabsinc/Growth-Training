### Routine Model Structure
[Source: Growth/Core/Models/RoutineModel.swift]

**Required Fields for Firestore Deployment:**
```javascript
{
  // Required fields
  "id": String,                    // Unique document ID (e.g., "routine_beginner_length_focused")
  "name": String,                  // Routine name
  "description": String,           // Routine description
  "difficulty": String,            // "beginner", "intermediate", "advanced" (enum rawValue)
  "duration": Number,              // Total days in routine
  "focusAreas": [String],          // e.g., ["length"], ["girth"], ["length", "girth"]
  "stages": [Number],              // Exercise stages included, e.g., [1], [1, 2], [1, 2, 3]
  "createdDate": Timestamp,        // Creation timestamp
  "lastUpdated": Timestamp,        // Last update timestamp
  "schedule": [DaySchedule],       // Array of day schedules
  "isCustom": Boolean,             // false for standard routines, true for user-created

  // Optional but recommended
  "createdBy": String,             // null for standard routines
  "shareWithCommunity": Boolean,   // false for standard routines
  "schedulingType": String,        // "sequential" or "weekday" (defaults to "sequential")
  "tags": [String],                // Tags for categorization
  "version": Number                // Version number (default: 1)
}
```

**DaySchedule Structure:**
```javascript
{
  "id": String,                    // UUID or unique day ID
  "day": Number,                   // Day number (1, 2, 3, ...)
  "description": String,           // Day description (e.g., "Heavy Day", "Rest Day")
  "isRestDay": Boolean,            // true for rest days, false for training days
  "methods": [MethodSchedule],     // Array of methods for this day
  "notes": String                  // Additional notes (e.g., "Keep session under 30 min")
}
```

**MethodSchedule Structure:**
```javascript
{
  "id": String,                    // UUID
  "methodId": String,              // Exercise document ID from growth_exercises
  "duration": Number,              // Duration in minutes
  "order": Number                  // Order in the day (0, 1, 2, ...)
}
```

**CRITICAL Firestore Field Naming:**
- Use camelCase for all fields (matches Swift model)
- `difficulty` field must use enum rawValue: "beginner", "intermediate", "advanced"
- `isCustom` MUST be `false` for all standard routines
- `schedule` array must contain complete DaySchedule objects with methods arrays

### Reddit-Sourced Routine Specifications
[Source: Epic 8 - Routine Templates to Create]

**Beginner Routines:**

1. **Length-Focused Beginner** (`routine_beginner_length_focused`)
   - Focus: Length gains through manual stretches or device wear
   - Duration: 7 days (repeating weekly pattern)
   - Target: 30-60 minutes per training day
   - Pattern: Daily manual stretches OR extended device wear (ADS/extender)
   - Rest: 1-2 rest days per week
   - Safety: Low risk, no devices required (optional ADS for passive wear)

2. **Balanced Beginner** (`routine_beginner_balanced`)
   - Focus: Alternating length/girth days for balanced gains
   - Duration: 7 days (repeating weekly pattern)
   - Exercises: Modified jelq + manual stretches on alternating days
   - Pattern: Length Day → Rest → Girth Day → Rest → Combined → Rest → Rest
   - Safety: Recovery-focused schedule prevents overtraining

**Intermediate Routines:**

3. **Intermediate Shock Loading** (`routine_intermediate_shock_loading`)
   - Focus: 5 min girth work before length for accelerated gains
   - Duration: 7 days (repeating weekly pattern)
   - Protocol: Brief pumping/jelqing → stretching/extending
   - Pattern: Daily training with active recovery days
   - Safety: Requires understanding of proper pressure/intensity

4. **Intermediate Pumping** (`routine_intermediate_pumping`)
   - Focus: Girth expansion through pumping protocols
   - Duration: 7 days (repeating weekly pattern)
   - Protocol: Static or interval pumping
   - Pattern: 1 on / 1 off schedule (train day, rest day, repeat)
   - Safety: Requires pump device and pressure monitoring

**Advanced Routines:**

5. **Advanced RIP Protocol** (`routine_advanced_rip`)
   - Focus: Maximum girth expansion through rapid interval pumping
   - Duration: 7 days (repeating weekly pattern)
   - Protocol: 30s pump / 30s release intervals for 30 minutes
   - Pattern: 1 on / 1 off with active recovery days
   - Safety: Experienced users only, strict pressure limits

6. **Advanced PAC Protocol** (`routine_advanced_pac`)
   - Focus: Pump-assisted clamping for extreme girth
   - Duration: 7 days (repeating weekly pattern)
   - Protocol: Pump to max expansion → clamp → pressure cycles
   - Pattern: 2 on / 1 off with strict safety protocols
   - Safety: Requires extensive PE experience, emergency protocols

### Routine Design Patterns
[Source: Epic 8, Reddit Best Practices]

**1on/1off Pattern:**
- Train one day, rest one day, repeat
- Used for: Intermediate Pumping, Advanced RIP
- Example: Day 1 (train) → Day 2 (rest) → Day 3 (train) → Day 4 (rest)

**2on/1off Pattern:**
- Train two days, rest one day, repeat
- Used for: Advanced PAC
- Example: Day 1 (train) → Day 2 (train) → Day 3 (rest) → Day 4 (train)

**Daily with Active Recovery:**
- Train most days with "light" recovery sessions
- Used for: Shock Loading, Length-Focused Beginner
- Example: Heavy → Light → Heavy → Light → Combined → Rest → Rest

**Alternating Focus:**
- Alternate between length and girth days
- Used for: Balanced Beginner
- Example: Length → Rest → Girth → Rest → Combined → Rest → Rest

**Progression Criteria:**
Routines should include `progressionCriteriaText` field suggesting:
- Time-based: "After 4-6 weeks of consistent practice..."
- Metric-based: "When you can comfortably handle X pressure for Y minutes..."
- Feeling-based: "When this routine feels easy and recovery is quick..."
- Safety-based: "Only progress when no negative PI (physiological indicators) present"

### Firestore Deployment Script Pattern
[Source: scripts/deploy-pe-exercises.js]

**Deployment Script Structure:**
```javascript
#!/usr/bin/env node

const admin = require('firebase-admin');

// Initialize Firebase Admin with Application Default Credentials
admin.initializeApp({
  projectId: process.env.GCLOUD_PROJECT || 'growth-training-app'
});

const db = admin.firestore();

// Helper to create MethodSchedule object
function createMethodSchedule(methodId, duration, order) {
  return {
    id: `method_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`,
    methodId: methodId,
    duration: duration,
    order: order
  };
}

// Helper to create DaySchedule object
function createDaySchedule(day, description, isRestDay, methods = [], notes = "") {
  return {
    id: `day_${day}_${Date.now()}`,
    day: day,
    description: description,
    isRestDay: isRestDay,
    methods: methods,
    notes: notes
  };
}

// Routine data array
const ROUTINES = [
  {
    id: "routine_beginner_length_focused",
    name: "Length-Focused Beginner",
    description: "Daily manual stretches or device wear focusing on length gains. Safety-first approach for beginners.",
    difficulty: "beginner",
    duration: 7,
    focusAreas: ["length"],
    stages: [1],
    schedule: [
      createDaySchedule(1, "Manual Stretch Day", false, [
        createMethodSchedule("stage1_basic_manual_stretch", 25, 0),
        createMethodSchedule("stage1_heat_application", 10, 1)
      ], "Keep total session under 40 minutes"),
      // ... more days
    ],
    isCustom: false,
    createdBy: null,
    shareWithCommunity: false,
    schedulingType: "sequential",
    tags: ["beginner", "length", "manual"],
    version: 1,
    createdDate: admin.firestore.FieldValue.serverTimestamp(),
    lastUpdated: admin.firestore.FieldValue.serverTimestamp()
  },
  // ... more routines
];

// Validation function
function validateRoutines() {
  const errors = [];

  ROUTINES.forEach((routine, index) => {
    if (!routine.id) errors.push(`Routine ${index}: Missing id`);
    if (!routine.difficulty || !["beginner", "intermediate", "advanced"].includes(routine.difficulty)) {
      errors.push(`Routine ${index}: Invalid difficulty`);
    }
    if (!routine.schedule || routine.schedule.length === 0) {
      errors.push(`Routine ${index}: Missing or empty schedule`);
    }
    if (routine.isCustom !== false) {
      errors.push(`Routine ${index}: Standard routines must have isCustom=false`);
    }
  });

  return errors;
}

// Batch write to Firestore
async function deployRoutines() {
  console.log("🔍 Validating routine data...");
  const validationErrors = validateRoutines();

  if (validationErrors.length > 0) {
    console.error("❌ Validation failed:");
    validationErrors.forEach(err => console.error(`  - ${err}`));
    process.exit(1);
  }

  console.log("✅ Validation passed");
  console.log(`📦 Deploying ${ROUTINES.length} routines to Firestore...`);

  const batch = db.batch();

  ROUTINES.forEach(routine => {
    const docRef = db.collection('routines').doc(routine.id);
    batch.set(docRef, routine);
  });

  await batch.commit();
  console.log(`✅ Deployed ${ROUTINES.length} routines successfully`);

  // Print summary
  const beginnerCount = ROUTINES.filter(r => r.difficulty === "beginner").length;
  const intermediateCount = ROUTINES.filter(r => r.difficulty === "intermediate").length;
  const advancedCount = ROUTINES.filter(r => r.difficulty === "advanced").length;

  console.log("\n📊 Deployment Summary:");
  console.log(`  - Beginner: ${beginnerCount}`);
  console.log(`  - Intermediate: ${intermediateCount}`);
  console.log(`  - Advanced: ${advancedCount}`);
  process.exit(0);
}

deployRoutines().catch(error => {
  console.error("❌ Deployment failed:", error);
  process.exit(1);
});
```

**Deployment Command:**
```bash
GCLOUD_PROJECT=growth-training-app node scripts/deploy-pe-routines.js
```
