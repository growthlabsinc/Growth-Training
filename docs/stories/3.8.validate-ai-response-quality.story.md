[Source: CLAUDE.md, Story 3.6-3.7]

**Response Generation Flow**:
```javascript
1. User query received with conversationHistory and userContext
2. Template selection via selectBestTemplate(query, userContext)
3. If template selected: processTemplate() with variable substitution
4. Knowledge base search via searchKnowledgeBase(query)
5. System prompt generation via generateSystemPrompt(knowledgeSources)
6. Vertex AI processing with Gemini model (gemini-2.0-flash-lite-001)
7. Response filtering via filterResponse(response, userContext)
8. Filtered response returned to client
```
[Source: /functions/vertexAiProxy/index.js]
