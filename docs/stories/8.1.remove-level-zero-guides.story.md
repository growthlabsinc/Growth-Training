# Story 8.1: Remove Level 0 Guides & Restructure Content

## Status
Done

## Story
**As a** Growth Training app user,
**I want** the method guides list to exclude beginner-level educational content (Level 0 guides),
**so that** I see only actionable training protocols in my routines while finding educational content in the Learning Center where it belongs.

## Acceptance Criteria
1. Level 0/Stage 0 training protocols are excluded from MethodsGuideView and routine selection UIs
2. Existing routines and saved user data continue to function without breaking changes
3. RoutineService correctly filters protocols based on stage level
4. TrainingProtocolService maintains backward compatibility with existing Firestore data
5. No UI regression in routine-related views (MethodsGuideView, DailyRoutineView, etc.)
6. Educational content (Level 0) is preserved in Firestore for future Learning Center migration

### TrainingProtocol Model Structure
[Source: Growth/Core/Models/TrainingProtocol.swift]

The TrainingProtocol class (formerly GrowthMethod) is the core data model for exercises:

**Key Fields:**
- `stage: Int` - Progression level (0 = educational, 1+ = actionable protocols)
- `classification: String?` - "Beginner", "Intermediate", "Advanced", "Foundation", "Expert", "Master"
- `title: String` - Protocol name
- `protocolDescription: String` - Brief description
- `instructionsText: String` - Detailed instructions
- `categories: [String]` - Tags like ["length", "girth", "conditioning", "eq"]
- `isFeatured: Bool` - Featured flag
- `equipmentNeeded: [String]` - Required equipment
- `estimatedDurationMinutes: Int?` - Duration
- `safetyNotes: String?` - Safety information
- `timerConfig: TimerConfiguration?` - Timer setup
- `steps: [MethodStep]?` - Structured steps

**Firestore Collection:** `growth_exercises` (preserved for backward compatibility)

**Filtering Logic:** Stage 0 protocols should be excluded from user-facing method selection UIs but preserved in database for future Learning Center migration.
