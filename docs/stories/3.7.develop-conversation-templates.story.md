#### Template Storage Options
**Option 1: In-code constants**
- Store in new file: `/functions/vertexAiProxy/conversationTemplates.js`
- Export as module for easy importing
- Pros: Fast access, version controlled
- Cons: Requires deployment for updates

**Option 2: Firestore collection**
- Collection: `conversation_templates`
- Structure: `{id, type, template, variables, priority}`
- Pros: Dynamic updates without deployment
- Cons: Additional database calls

#### Template Variable System
Templates should support variable substitution:
```javascript
const template = "Welcome {{userName}}. Based on your {{experienceLevel}} level...";
const variables = { userName: "John", experienceLevel: "beginner" };
// Result: "Welcome John. Based on your beginner level..."
```

#### Context Detection for Template Selection
Use existing data from request:
- `userContext.userExperienceLevel` (beginner/intermediate/advanced)
- `userContext.sessionType` (general/specific)
- Query content analysis for intent detection
- Conversation history for context continuity
[Source: functions/vertexAiProxy/responseFilter.js#userContext]

### Safety Integration Requirements

**Mandatory Safety Elements** (from Epic 3 Safety Framework):
- All templates must include relevant safety disclaimers
- Beginner templates emphasize conservative approach
- Injury-related templates prioritize immediate cessation
- Medical consultation recommendations where appropriate
- Never exceed safety guardrails:
  - maxDuration: 60 minutes
  - maxFrequency: "daily"
  - requiredRest: 1 day per week
  - beginnerLimit: 15 minutes
[Source: docs/prd/epic-3-ai-coach.md#AI-Safety-Framework]
