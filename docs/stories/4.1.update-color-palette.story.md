### ThemeManager Implementation Details

**Current Theme Manager Features**:
- **AppStorage** properties for user theme preferences
- **@Published** properties for reactive color updates
- Support for system/light/dark color schemes
- Accent color customization (blue, purple, orange, red, green)
- Large text support for accessibility
- Reduce motion support
- Haptic feedback control
- First day of week preference

**Key Methods**:
- `updateTheme()` - Updates color scheme based on user preference
- `updateAccentColor()` - Updates accent color throughout app
- `scaledSystemFont()` - Returns accessibility-scaled fonts
- `performHapticFeedback()` - Handles haptic feedback
- `animationDuration()` / `animation()` - Respects reduce motion setting

**View Extensions**:
- `applyTheme()` - Applies theme modifier to views
- `themedFont()` - Applies themed font sizes
- `themedAnimation()` - Applies animations respecting reduce motion
- `accessibleSystemFont()` - Applies accessibility-scaled fonts

### Color Migration Strategy

1. **Update AppColors.swift** with new hex values while maintaining existing enum names for backward compatibility
2. **Update ThemeManager.swift** default accent color reference
3. **Update Assets.xcassets** color sets to use new hex values
4. **Preserve dark mode logic** - all colors must have light and dark variants
5. **Maintain semantic color system** - success, warning, error colors
6. **Test across all screens** to ensure no visual regressions

### Dark Mode Requirements

All colors MUST support dark mode with proper contrast:
- Primary deep blue: Lighter shade for dark mode visibility
- Growth green: Adjust saturation for dark backgrounds
- Energy orange: Ensure sufficient contrast on dark surfaces
- Background colors: Invert appropriately (#F8FAFC → dark equivalent)
- Text colors: Invert for readability (#1E293B → light equivalent)

[Source: iOS Human Interface Guidelines - Dark Mode]

### Accessibility Requirements

**WCAG 2.1 Contrast Standards**:
- **Normal text** (< 18pt): 4.5:1 minimum contrast ratio
- **Large text** (≥ 18pt or ≥ 14pt bold): 3:1 minimum contrast ratio
- **UI components**: 3:1 minimum contrast ratio

**Tools for Verification**:
- Xcode Accessibility Inspector
- WebAIM Contrast Checker (online tool)
- Test with iOS Accessibility settings (Increase Contrast, Reduce Transparency)

[Source: WCAG 2.1 Level AA Guidelines]
