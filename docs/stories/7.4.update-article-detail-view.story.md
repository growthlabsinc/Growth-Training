### Component Design Specification

**CitationRowView Component** (NEW FILE):

File: `Growth/Features/EducationalResources/Views/Components/CitationRowView.swift`

```swift
struct CitationRowView: View {
    let citation: Citation

    var body: some View {
        VStack(alignment: .leading, spacing: 4) {
            // Display APA formatted citation
            Text(citation.formattedAPA)
                .font(AppTheme.Typography.captionFont())
                .foregroundColor(AppTheme.Colors.text)
                .fixedSize(horizontal: false, vertical: true) // Allow text wrapping

            // "View Source" link (if URL available)
            if let url = citation.url, let validURL = URL(string: url) {
                Link("View Source →", destination: validURL)
                    .font(AppTheme.Typography.captionFont())
                    .foregroundColor(AppTheme.Colors.primary)
                    .padding(.top, 2)
            }
        }
        .padding(.vertical, AppTheme.Layout.spacingS)
        .accessibilityElement(children: .combine)
        .accessibilityLabel("Citation: \(citation.formattedAPA)")
    }
}
```

**Design Rationale**:
- Simple, reusable component for each citation
- Uses AppTheme for consistency with existing app design
- Handles nil URL gracefully (no link displayed)
- Accessibility: combines citation and link into single VoiceOver element
- Vertical padding for touch target spacing

[Source: docs/prd/epic-7-learning-center-content.md#Story 7.4 UI Components]
