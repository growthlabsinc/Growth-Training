**AnonymizationService (Story 11.1)** is already implemented:
```swift
// Location: Growth/Core/Services/AnonymizationService.swift
class AnonymizationService {
    static let shared = AnonymizationService()

    func getOrCreateAnonymousId() -> String       // Returns GT-XXXXXXXX
    func regenerateAnonymousId() -> String         // Returns new ID (rate limited)
    func canRegenerateId() -> Bool                 // Check if can regenerate
    func timeUntilCanRegenerate() -> TimeInterval  // Seconds until rate limit expires
}
```

**Rate limiting:** 24 hours between regenerations. Use `canRegenerateId()` to check, `timeUntilCanRegenerate()` for countdown.

**First-time user behavior:** If a user has never regenerated their ID, `canRegenerateId()` returns `true` (regeneration allowed) and `timeUntilCanRegenerate()` returns `0`.

### Time Formatting Helper
[Source: Swift Foundation]

```swift
private func formatTimeRemaining(_ seconds: TimeInterval) -> String {
    let hours = Int(seconds) / 3600
    let minutes = (Int(seconds) % 3600) / 60
    if hours > 0 {
        return "\(hours)h \(minutes)m"
    } else {
        return "\(minutes)m"
    }
}
```
