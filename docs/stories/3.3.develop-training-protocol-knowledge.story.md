### Content Guidelines
Each document must include:
1. **Title**: Clear, descriptive (e.g., "Manual Stretching for Beginners")
2. **Category**: One of: length, girth, eq, equipment, progression, safety
3. **Level**: Beginner/Intermediate/Advanced where applicable
4. **Prerequisites**: Required experience, equipment, or previous techniques
5. **Instructions**: Step-by-step guidance with timing and repetitions
6. **Safety Warnings**: Specific risks and prevention measures
7. **Expected Results**: Realistic timelines (months/years, not weeks)
8. **Medical Disclaimer**: Standard disclaimer text
[Source: Epic 3 requirements]

### Safety Integration Requirements
Every protocol document must:
- Start with safety warnings in first paragraph
- Include "stop if" conditions (pain, numbness, discoloration)
- Reference medical consultation for concerns
- Provide conservative alternatives to aggressive techniques
- Emphasize gradual progression over weeks/months
- Use priority 8-10 for safety-critical content
[Source: Epic 3 Safety Framework, Story 3.2 audit requirements]

### Technical Constraints
- Firebase Firestore document size limit: 1MB per document
- Batch write limit: 500 documents per batch
- Keywords array should have 5-15 terms for optimal search
- Content should be 1000-5000 characters for depth without exceeding limits
- Use markdown formatting in content field for structure
