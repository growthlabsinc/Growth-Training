### App Icon Design Requirements

**iOS App Icon Specifications**:
- **Source Asset**: 1024x1024px PNG (no alpha channel)
- **Required Sizes** (iOS 16+):
  - iPhone: 20x20, 29x29, 40x40, 60x60, 76x76, 83.5x83.5, 1024x1024 (at @2x and @3x)
  - iPad: Same sizes at @1x, @2x
  - App Store: 1024x1024

**Design Guidelines**:
- **Simple and recognizable** at small sizes
- **No transparency** (solid background required)
- **Professional aesthetic** matching scientific app category
- **GT monogram** or abstract growth symbol
- **Color palette**: Use Deep Blue and Energy Orange from Story 4.1
- **Avoid text** (must be legible at 20x20 pixels)
- **Distinct silhouette** for recognition

[Source: Apple Human Interface Guidelines - App Icons]

### Launch Screen Design Requirements

**iOS Launch Screen Best Practices**:
- **Identical to first screen** of app (or simplified version)
- **No branding slogans** or marketing content
- **No "Loading..."** text or spinners
- **Static image** only (no animations)
- **Supports light and dark mode**
- **Proper constraints** for all device sizes

**Launch Screen Transition**:
- LaunchScreen.storyboard → First SwiftUI view
- Ensure smooth transition without flash or color mismatch
- First app screen should use same background color as launch screen

[Source: Apple Human Interface Guidelines - Launch Screens]

### Implementation Strategy

**Recommended Approach**:
1. **Design Phase**:
   - Create 1024x1024 source icon in design tool (Figma, Sketch, or AI)
   - Design launch screen matching new color palette
   - Get stakeholder approval before implementation

2. **Icon Implementation**:
   - Use Xcode's AppIcon generator (drag 1024x1024 into AppIcon.appiconset)
   - Xcode will auto-generate all required sizes
   - Verify all slots are filled in Assets.xcassets

3. **Launch Screen Implementation**:
   - Update LaunchScreen.storyboard with new branding
   - Use new colors from ColorExtensions.swift (from Story 4.1)
   - Ensure constraints work on all device sizes

4. **Testing**:
   - Build and run on physical device
   - Test icon on home screen
   - Verify launch screen transition is smooth
   - Test on multiple device sizes
