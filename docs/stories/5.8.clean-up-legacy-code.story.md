- Unused imports (import statements for frameworks not used in file)
- Deprecated methods marked with `@available(*, deprecated)`
- FIXME, XXX, HACK, TODO markers (~20 found in codebase)

- Unreachable code after `return` or `fatalError()`

- `print()` statements in production code (not in debug-only blocks)

- Test data generators in production code
- Commented-out debug logs

### Code Search Patterns

**To Find Legacy Code**:
```bash

# Find "method" in comments (context check needed)

# Find unused imports (requires manual review)
```
