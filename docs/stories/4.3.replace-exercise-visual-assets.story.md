### iOS Image Asset Requirements

**Resolution Variants**:
- **@1x**: Base resolution (e.g., 100x100px)
- **@2x**: Double resolution (e.g., 200x200px) - iPhone standard
- **@3x**: Triple resolution (e.g., 300x300px) - iPhone Plus/Pro models

**File Format**:
- **PNG**: Preferred format, supports transparency
- **JPEG**: For photos without transparency
- **PDF**: Vector format (single file, scales automatically)

**Asset Catalog Structure** (Contents.json):
```json
{
  "images" : [
    {
      "filename" : "image_name.png",
      "idiom" : "universal",
      "scale" : "1x"
    },
    {
      "filename" : "image_name@2x.png",
      "idiom" : "universal",
      "scale" : "2x"
    },
    {
      "filename" : "image_name@3x.png",
      "idiom" : "universal",
      "scale" : "3x"
    }
  ],
  "info" : {
    "author" : "xcode",
    "version" : 1
  }
}
```

[Source: Apple Human Interface Guidelines - Images]

### Dark Mode Support

**Dark Mode Image Variants** (optional but recommended):

- Add "Any, Dark" appearance in Contents.json for dark mode versions
- Adjust image brightness/contrast for dark backgrounds

```json

```

### Image Usage in SwiftUI

**How Images are Referenced**:
