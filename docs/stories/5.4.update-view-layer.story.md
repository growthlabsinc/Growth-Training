### String Update Patterns

**Replace Patterns**:
```swift
// Navigation titles
"Methods" → "Protocols"
"Method Details" → "Protocol Details"
"Daily Methods" → "Daily Protocols"
"Select Method" → "Select Protocol"

// Button labels
"Start Method" → "Start Protocol"
"View All Methods" → "View All Protocols"
"Add Method" → "Add Protocol"
"Choose Method" → "Choose Protocol"

// Accessibility labels
.accessibilityLabel("Method card") → .accessibilityLabel("Protocol card")
.accessibilityHint("Tap to view method") → .accessibilityHint("Tap to view protocol")

// VoiceOver support
"Selected method: \(name)" → "Selected protocol: \(name)"
```
