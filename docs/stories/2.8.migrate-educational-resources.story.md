### Data Models
```swift
// Educational content will use existing exercise structure
struct EducationalContent {
    let id: String  // e.g., "anatomy_guide", "growth_theory", "faq_guide"
    let title: String
    let description: String
    let category: String  // "education" for all educational content
    let difficulty: String  // "beginner" for accessibility
    let estimatedDuration: Int  // reading time in minutes
    let equipmentNeeded: [String]  // empty for educational content
    let steps: [ExerciseStep]  // 8 detailed educational steps
}

struct ExerciseStep {
    let stepNumber: Int  // CRITICAL: Use stepNumber not order
    let title: String  // e.g., "Step 1: Understanding Basic Anatomy"
    let description: String  // CRITICAL: Use description not instruction
    let tips: [String]  // Key learning points
    let cautions: [String]  // Common misconceptions to avoid
    let warnings: [String]  // Important disclaimers
}
```
[Source: Firebase document structure from growth_exercises collection]

### API Specifications
Firebase REST API for adding educational content:
- URL: `https://firestore.googleapis.com/v1/projects/growth-training-app/databases/(default)/documents/growth_exercises/{content_id}`
- Method: PATCH for updates, POST for new documents
- Auth: Bearer token from `gcloud auth print-access-token`
- Document format must exactly match existing structure
- Content will use category="education" to distinguish from exercises and equipment

### Educational Content Requirements
All educational resources MUST include:
- Scientific accuracy with medical/research citations
- Accessible language for general audience
- Clear debunking of common myths with evidence
- Realistic expectations and timelines
- Anatomical accuracy with proper terminology
- Growth mechanism explanations based on tissue science
- Nutritional and lifestyle factors with research backing
- Proper measurement techniques and statistical context
- Medical disclaimers and consultation recommendations
- No exaggerated claims or unrealistic promises
[Source: Epic 2 requirements and Story 2.8 acceptance criteria]

### Educational Content Categories
1. **Anatomy Education**
   - Penile anatomy (corpus cavernosum, corpus spongiosum, tunica albuginea)
   - Suspensory ligament structure and function
   - Blood flow and nerve distribution
   - Growth mechanism at cellular level

2. **Growth Theory**
   - Tissue expansion principles
   - Hypertrophy vs hyperplasia
   - Collagen remodeling process
   - Realistic timeline expectations (6-24 months)

3. **FAQ Section**
   - Common beginner questions
   - Myth debunking with evidence
   - Troubleshooting guide
   - Best practices from community

4. **Nutrition & Supplementation**
   - Nutritional factors for tissue health
   - Evidence-based supplements
   - Hydration importance
   - Cardiovascular health connection

5. **Measurement & Tracking**
   - BPEL, NBPEL, EG measurement techniques
   - Measurement frequency (monthly recommended)
   - Photo documentation guidelines
   - Statistical significance of gains

6. **Lifestyle Factors**
   - Sleep and recovery importance
   - Exercise and cardiovascular health
   - Stress management
   - Psychological aspects and realistic goals
