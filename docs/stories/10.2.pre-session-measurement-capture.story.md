# Story 10.2: Pre-Session Measurement Capture UI

## Status
Done

## Story
**As a** Growth Training user,
**I want** to optionally record pre-session measurements (BPEL, BPFSL, MSEG) before starting a practice session,
**so that** I can track yield/temporary gains after my session and understand session effectiveness.

## Acceptance Criteria
1. Pre-session measurement prompt appears when user starts a timer-based session (can be skipped)
2. Measurement input supports BPEL, BPFSL, MSEG only (GrowthTrack primary metrics)
3. Hard limit validation rejects values outside 3.0-11.0" for BPEL/BPFSL, 3.0-8.0" for MSEG
4. Soft limit validation shows confirmation dialog for values outside typical range (4.0-10.0" BPEL/BPFSL, 3.5-6.5" MSEG)
5. Pre-measurements stored in memory during session, persisted to SessionLog when session completes
6. User can skip pre-session measurements without blocking session start
7. Manual session logging (LogSessionView) also supports optional pre-measurement entry
8. Existing timer and session logging flows remain fully functional

### Validation Limits (GrowthTrack Standards)
[Source: Epic 10 - Technical Notes, docs/prd/epic-10-session-measurement-tracking.md:203-214]

**Hard Limits (Reject Immediately):**
- BPEL: 3.0" - 11.0" (75mm - 280mm)
- BPFSL: 3.0" - 11.0" (75mm - 280mm)
- MSEG: 3.0" - 8.0" (75mm - 200mm)

**Soft Limits (Confirmation Dialog):**
- BPEL: 4.0" - 10.0" (100mm - 250mm)
- BPFSL: 4.0" - 10.0" (100mm - 250mm)
- MSEG: 3.5" - 6.5" (90mm - 165mm)

**Validation Logic:**
```swift
enum ValidationResult {
    case valid
    case softLimitWarning(message: String)
    case hardLimitError(message: String)
}

func validate(value: Double, type: MeasurementType) -> ValidationResult {
    // 1. Check hard limits first (reject)
    if !isWithinHardLimits(value, type) {
        return .hardLimitError("Value must be between X and Y")
    }

    // 2. Check soft limits (warn, allow continue)
    if !isWithinSoftLimits(value, type) {
        return .softLimitWarning("This value is outside the typical range. Are you sure?")
    }

    return .valid
}
```
