### Multi-Environment Firebase Architecture

**Environment Configuration**:
```swift
enum FirebaseEnvironment: String {
    case development = "dev"
    case staging = "staging"
    case production = "prod"

    var configFileName: String {
        switch self {
        case .development:
            return "dev.GoogleService-Info"
        case .staging:
            return "staging.GoogleService-Info"
        case .production:
            return "GoogleService-Info"
        }
    }
}
```

**Initialization Order**:
1. Configure App Check FIRST (before Firebase.configure())
2. Initialize Firebase with environment-specific options
3. Enable Analytics, Crashlytics, InAppMessaging
4. Configure Firestore settings (SSL enabled)
5. Retrieve and validate App Check token

**CRITICAL**: App Check MUST be configured before FirebaseApp.configure() or initialization will fail.

### App Check Configuration

**Environment-Specific Providers**:
```swift
#if targetEnvironment(simulator)
    // Simulator: Enhanced Debug Provider
    let providerFactory = EnhancedDebugAppCheckProviderFactory()
#elseif DEBUG
    // Real device debug: Enhanced Debug Provider
    let providerFactory = EnhancedDebugAppCheckProviderFactory()
#else
    // Production: App Attest Provider (iOS 14+)
    let providerFactory = AppAttestAppCheckFactory()
#endif
AppCheck.setAppCheckProviderFactory(providerFactory)
```

[Source: Growth/Core/Networking/FirebaseClient.swift:142-187]

**Debug Token Management**:
- Debug tokens stored in UserDefaults key: "FIRAAppCheckDebugToken"
- App includes UI for debug token management (AppCheckDebugView)
- Debug tokens must be registered in Firebase Console
- Firebase Console URL: https://console.firebase.google.com/project/growth-training-app/appcheck/apps

[Source: Growth/Core/Networking/FirebaseClient.swift:163-176, 202-237]

**App Check Methods**:
- `configureAppCheck()` - Initialize App Check provider
- `getStoredDebugToken()` - Retrieve debug token from UserDefaults
- `clearAppCheckTokenCache()` - Clear and regenerate debug tokens
- `retrieveAppCheckToken()` - Fetch and validate token

[Source: Growth/Core/Networking/FirebaseClient.swift:141-239]

### GoogleService-Info.plist Structure

**Required Keys**:
Each GoogleService-Info.plist must contain:
- `BUNDLE_ID` - Must match com.growthlabs.growthtraining (or .dev/.staging variants)
- `PROJECT_ID` - Firebase project identifier
- `GOOGLE_APP_ID` - Unique app identifier in Firebase
- `API_KEY` - Firebase API key
- `GCM_SENDER_ID` - Push notification sender ID
- `CLIENT_ID` - OAuth client ID
- `REVERSED_CLIENT_ID` - URL scheme for OAuth
