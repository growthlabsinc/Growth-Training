### Firestore Integration

**Collection Name**: `"growth_exercises"` (MUST NOT CHANGE)

[Source: Growth/Core/Services/GrowthMethodService.swift:22]

**Field Mapping Strategy**:
The model uses dual field name support for Firebase compatibility:
- Swift property names: `camelCase` (e.g., `methodDescription`)
- Firestore field names: `snake_case` (e.g., `description`, `instructions_text`)

Example from `init(document:)`:
```swift
// Handles both field naming conventions
let instructionsText: String
if let text = data["instructions_text"] as? String {
    instructionsText = text
} else if let text = data["instructionsText"] as? String {
    instructionsText = text
} else {
    instructionsText = "No instructions provided"
}
```

### NSSecureCoding Implementation

**Purpose**: Required for local caching and UserDefaults storage

**Key Requirements**:
- `supportsSecureCoding` must return true
- All properties must be encoded/decoded with proper keys
- Complex types (TimerConfiguration, steps) encoded as JSON Data
- Type-safe decoding with NSString, NSArray, NSData classes

[Source: Growth/Core/Models/GrowthMethod.swift:75-237]

**Encoding Example**:
```swift
public func encode(with coder: NSCoder) {
    coder.encode(id, forKey: "id")
    coder.encode(stage, forKey: "stage")
    coder.encode(title, forKey: "title")
    coder.encode(methodDescription, forKey: "description")
    // ... complex JSON encoding for nested objects
    if let timerConfig = timerConfig {
        let timerConfigData = try JSONEncoder().encode(timerConfig)
        coder.encode(timerConfigData, forKey: "timerConfig")
    }
}
```
