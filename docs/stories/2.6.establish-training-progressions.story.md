### Data Models
```swift
// Routine data structure (separate from exercises)
struct TrainingRoutine {
    let id: String  // e.g., "newbie_routine_week1", "intermediate_length"
    let title: String
    let description: String
    let difficulty: String  // "beginner", "intermediate", "advanced"
    let category: String  // "progression", "specialization", "maintenance"
    let duration: Int  // total routine duration in minutes
    let exerciseIds: [String]  // references to exercises in growth_exercises
    let schedule: RoutineSchedule
    let progressionCriteria: [String]
}

struct RoutineSchedule {
    let daysPerWeek: Int
    let weeksInProgram: Int
    let restDayRequirements: String
    let timeCommitment: String
}

// Exercises continue to use existing structure
struct PEExercise {

    let difficulty: String  // "beginner", "intermediate", "advanced"
    let estimatedDuration: Int  // minutes
    let equipmentNeeded: [String]
```

### Training Progression Requirements
All training progression routines MUST include:
- Clear difficulty level designation (beginner/intermediate/advanced)
- Realistic time commitments and expectations
- Reference to existing exercises by ID (not create new exercises)
- Progressive advancement criteria
- Safety considerations and medical disclaimers
- Rest day requirements and recovery protocols
- Equipment requirements clearly specified
- Expected timeline for advancement to next level
[Source: Epic 2 requirements and safety framework from Story 2.5]

### Progression Structure Needed
1. **Newbie Level (Beginner)**
   - 3-month initial conditioning program
   - Conservative starting exercises
   - Focus on safety and technique
   - Gradual intensity increase

2. **Intermediate Level**
   - 6-month programs with specialization options
   - Increased intensity and duration
   - Plateau breaking techniques
   - Multiple routine variations

3. **Advanced Level**
   - High intensity protocols
   - Combination approaches
   - Maintenance programs
   - Long-term sustainability

NOTE: These are ROUTINES that reference individual exercises by ID. Routines will be stored in a separate Firebase collection and will organize exercises from the growth_exercises collection into structured training programs.
[Source: Epic 2 content structure and Firebase architecture]
