### Live Activity Architecture

**Core Components**:
- **TimerActivityAttributes.swift** - Live Activity data model with ContentState (iOS 16.1+)
- **LiveActivityManager.swift** - Activity lifecycle management
- **Widget Extension** in `GrowthTimerWidget/` directory
- **startedAt/pausedAt pattern** for pause/resume functionality

[Source: CLAUDE.md#Live Activity Architecture]

**Key Implementation Patterns**:
- Use `Text(timerInterval:)` for efficient native timer displays
- startedAt/pausedAt pattern for pause/resume
- App Intents (iOS 17.0+) for Dynamic Island interactions
- Minimize ContentState data - keep under 4KB
- **CRITICAL**: Live Activities require physical device testing - simulator support limited

[Source: CLAUDE.md#Live Activity Best Practices]

**File Locations**:
- **Main data model**: `Growth/Features/Timer/Models/TimerActivityAttributes.swift`
