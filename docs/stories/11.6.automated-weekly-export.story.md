# Story 11.6: Automated Weekly GrowthTrack Export

## Status
**Draft**

## Story
**As** Karl (GrowthTrack researcher),
**I want** to receive weekly automated CSV exports from all opted-in Growth Training users,
**so that** I can build a comprehensive PE research dataset without relying on manual user submissions.

## Acceptance Criteria
1. Firebase Cloud Function scheduled to run weekly (Sunday 00:00 UTC)
2. Function queries all users with `growthTrackOptIn === true`
3. For each opted-in user, fetch all SessionLogs since last export
4. Generate single aggregated CSV with all opted-in users' data
5. Upload CSV to Firebase Cloud Storage with filename: `growthtrack-export-YYYY-MM-DD.csv`
6. Generate signed URL for CSV download (7-day expiration)
7. Send email to Karl (wikman.karl@gmail.com) with download link
8. Email includes: user count, session count, date range, download link
9. Log export metadata to Firestore audit collection for compliance
10. Update user records with `lastExportedAt` timestamp
11. Handle errors gracefully with email notification to Growth Training admin
12. CSV format identical to manual export (Story 11.2 compatibility)

## Dev Notes

### Scheduled Functions Pattern
[Source: Firebase Functions documentation - Schedule functions]

```javascript
const functions = require('firebase-functions');
const admin = require('firebase-admin');

exports.weeklyGrowthTrackExport = functions.pubsub
  .schedule('0 0 * * 0') // Every Sunday at midnight UTC
  .timeZone('America/Los_Angeles')
  .onRun(async (context) => {
    console.log('Starting weekly GrowthTrack export...');

    try {
      // 1. Query opted-in users
      const usersSnapshot = await admin.firestore()
        .collection('users')
        .where('growthTrackOptIn', '==', true)
        .get();

      if (usersSnapshot.empty) {
        console.log('No opted-in users found');
        return null;
      }

      // 2. Fetch sessions for each user
      const allSessions = [];
      for (const userDoc of usersSnapshot.docs) {
        const userId = userDoc.id;
        const lastExported = userDoc.data().lastExportedAt?.toDate() || new Date(0);

        const sessionsSnapshot = await admin.firestore()
          .collection('sessionLogs')
          .where('userId', '==', userId)
          .where('startTime', '>', lastExported)
          .get();

        sessionsSnapshot.docs.forEach(doc => {
          allSessions.push({ ...doc.data(), docId: doc.id });
        });
      }

      if (allSessions.length === 0) {
        console.log('No new sessions to export');
        return null;
      }

      // 3. Generate CSV (reuse Story 11.2 logic)
      const csvContent = generateCSVContent(allSessions);

      // 4. Upload to Cloud Storage
      const fileName = `growthtrack-export-${new Date().toISOString().split('T')[0]}.csv`;
      const bucket = admin.storage().bucket();
      const file = bucket.file(`growthtrack-exports/${fileName}`);
      await file.save(csvContent, { contentType: 'text/csv' });

      // 5. Generate signed URL
      const [url] = await file.getSignedUrl({
        action: 'read',
        expires: Date.now() + 7 * 24 * 60 * 60 * 1000 // 7 days
      });

      // 6. Send email via SendGrid
      await sendExportEmail({
        url,
        userCount: usersSnapshot.size,
        sessionCount: allSessions.length,
        dateRange: getDateRange(allSessions)
      });

      // 7. Update user records
      const batch = admin.firestore().batch();
      usersSnapshot.docs.forEach(doc => {
        batch.update(doc.ref, { lastExportedAt: admin.firestore.FieldValue.serverTimestamp() });
      });
      await batch.commit();

      // 8. Log audit trail
      await admin.firestore().collection('growthtrack_exports').add({
        timestamp: admin.firestore.FieldValue.serverTimestamp(),
        userCount: usersSnapshot.size,
        sessionCount: allSessions.length,
        csvUrl: url,
        success: true
      });

      console.log(`Export complete: ${allSessions.length} sessions from ${usersSnapshot.size} users`);
      return null;

    } catch (error) {
      console.error('Export failed:', error);
      await sendErrorEmail(error);

      // Log failure
      await admin.firestore().collection('growthtrack_exports').add({
        timestamp: admin.firestore.FieldValue.serverTimestamp(),
        success: false,
        errorMessage: error.message
      });

      throw error;
    }
  });
```

### SendGrid Email Template
[Source: SendGrid API documentation]

```javascript
const sgMail = require('@sendgrid/mail');

async function sendExportEmail({ url, userCount, sessionCount, dateRange }) {
  sgMail.setApiKey(functions.config().sendgrid.key);

  const msg = {
    to: 'wikman.karl@gmail.com',
    from: 'noreply@growthlabs.com',
    subject: `Growth Training Weekly Export - ${new Date().toISOString().split('T')[0]}`,
    text: `
Growth Training Weekly Data Export

Summary:
- Users: ${userCount}
- Sessions: ${sessionCount}
- Date Range: ${dateRange}

Download CSV: ${url}

This link expires in 7 days.

Note: All data is anonymized with statistical IDs. No PII included.
    `.trim(),
    html: `
      <h2>Growth Training Weekly Data Export</h2>
      <p><strong>Summary:</strong></p>
      <ul>
        <li>Users: ${userCount}</li>
        <li>Sessions: ${sessionCount}</li>
        <li>Date Range: ${dateRange}</li>
      </ul>
      <p><a href="${url}" style="background: #4CAF50; color: white; padding: 10px 20px; text-decoration: none; border-radius: 5px;">Download CSV</a></p>
      <p><em>This link expires in 7 days.</em></p>
      <hr>
      <p style="color: #666; font-size: 12px;">
        All data is anonymized with statistical IDs. No personally identifiable information included.
      </p>
    `
  };

  await sgMail.send(msg);
  console.log('Export email sent to Karl');
}
```

- Cloud Storage: $0.020 per GB/month

### Privacy & GDPR Compliance
[Source: Epic 11 PRD - Privacy & Ethics section]

**CRITICAL Requirements:**
1. **Explicit opt-in:** User must actively enable automated export (default: OFF)
2. **Clear disclosure:** Settings must explain "weekly automated export" clearly
3. **Right to withdraw:** User can disable anytime, no future exports
4. **Audit trail:** Log every export (timestamp, userCount, anonymousIds)
5. **Data processor agreement:** Need written agreement with Karl/GrowthTrack

Data Collaboration with Research Platforms

If you opt-in to automated GrowthTrack export:
