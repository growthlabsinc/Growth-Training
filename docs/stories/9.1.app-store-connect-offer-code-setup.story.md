# Story 9.1: App Store Connect Offer Code Setup

## Status
Approved

## Story
**As a** Growth Training marketing team member,
**I want** subscription offer codes configured in App Store Connect,
**so that** I can distribute promotional codes to influencers and partners for free or discounted annual subscriptions.

## Acceptance Criteria
1. At least one active offer configured (e.g., "INFLUENCER_ANNUAL_FREE")
2. Custom codes generated and ready for distribution
3. Documentation created for creating/managing future offer codes

## Tasks / Subtasks

- [ ] Task 1: Configure subscription offer in App Store Connect (AC: 1)
  - [ ] Log into App Store Connect (https://appstoreconnect.apple.com)
  - [ ] Navigate to: My Apps → Growth Training → Subscriptions
  - [ ] Select the annual subscription product ($49.99/year)
  - [ ] Click "Subscription Prices" → "Set Up Offer Codes"
  - [ ] Create new offer with the following configuration:
    - **Reference Name**: `INFLUENCER_ANNUAL_FREE`
    - **Offer Type**: Free
    - **Duration**: 12 months (full annual period)
    - **Number of Periods**: 1
    - **Customer Eligibility**: New and Existing Subscribers
  - [ ] Save and activate the offer

- [ ] Task 2: Generate custom offer codes for distribution (AC: 2)
  - [ ] In the offer configuration, select "Create Custom Codes"
  - [ ] Configure custom code settings:
    - **Code Type**: Custom
    - **Maximum Number of Codes**: 50 (initial batch for influencers)
    - **One-Time Use**: Enabled (each code can only be used once)
  - [ ] Generate the codes
  - [ ] Download the generated codes as CSV file
  - [ ] Store CSV securely in password-protected location (not in version control)

- [ ] Task 3: Create offer code distribution tracking system (AC: 2)
  - [ ] Create spreadsheet template for code distribution tracking with columns:
    - Code Value
    - Assigned To (influencer name/handle)
    - Distribution Date
    - Redemption Status (Pending/Redeemed/Expired)
    - Redemption Date (if applicable)
    - Notes
  - [ ] Import generated codes from CSV into tracking spreadsheet
  - [ ] Save tracking spreadsheet in secure location

- [ ] Task 4: Document offer code management process (AC: 3)
  - [ ] Create `docs/app-store-offer-codes-guide.md` documentation file
  - [ ] Document step-by-step process for creating new offers
  - [ ] Document how to generate additional custom codes
  - [ ] Document how to check redemption status in App Store Connect
  - [ ] Document code distribution workflow and tracking system
  - [ ] Include Apple's limits and constraints:
    - Up to 10 active offers per subscription
    - Max 1,000,000 redemptions per app per quarter
    - Code expiration timeline (if applicable)
  - [ ] Document where to find redemption analytics in App Store Connect

- [ ] Task 5: Validate offer code configuration (AC: 1)
  - [ ] Verify offer appears as "Active" in App Store Connect
  - [ ] Confirm customer eligibility settings are correct
  - [ ] Verify offer duration matches intended 12 months
  - [ ] Test one code redemption using TestFlight build (if available)
  - [ ] Document any issues or configuration adjustments needed

## Dev Notes

### Subscription Product Configuration Context
[Source: docs/architecture/tech-stack.md#subscription-products-storekit]

**Current Subscription Products:**
- Weekly: $4.99 (com.growthlabs.growthmethod.subscription.premium.weekly)
- 3-Month: $29.99 (com.growthlabs.growthmethod.subscription.premium.quarterly)
- Yearly: $49.99 (com.growthlabs.growthmethod.subscription.premium.yearly)

**Target Product for Offer Code:**
The offer code should be configured for the **Yearly subscription** ($49.99/year) as specified in Epic 9 goal for "free annual subscriptions."

### Apple Offer Code Limitations
[Source: Epic 9 - Apple Documentation Reference]

**App Store Connect Limits:**
- Up to 10 active offers per subscription product
- Maximum 1,000,000 redemptions per app, per quarter
- Two types of codes: one-time use codes and custom codes

**Offer Code Types:**
- **One-time use codes**: Automatically generated by Apple, each can only be used once
- **Custom codes**: You define the code text, can be used multiple times or once (configurable)

### Offer Code Redemption Flow
[Source: Epic 9 - Epic Description]

When a user redeems an offer code:
1. Code validation handled by Apple (expiration, eligibility, usage limits)
2. App receives transaction with `offer_code_ref_name` field in receipt
3. Firebase backend will track redemption (implemented in Story 9.3)
4. User gets subscription access based on offer configuration

### App Store Connect Access
[Source: docs/app-store-connect-api-setup.md#security-best-practices]

**Prerequisites:**
- Apple Developer account with Admin or App Manager role
- Access to Growth Training app in App Store Connect
- Two-factor authentication enabled for Apple ID

**Navigation Path:**
App Store Connect → My Apps → Growth Training → Features → In-App Purchases → Subscriptions → Select Product → Set Up Offer Codes

### Security Considerations
[Source: docs/app-store-connect-api-setup.md#security-best-practices]

**Code Distribution Security:**
- Never commit generated codes to version control
- Store codes in password-protected spreadsheet
- Track code distribution to prevent unauthorized use
- Implement expiration dates for time-sensitive campaigns

### Reference Name Convention
[Source: Epic 9 - Story 9.1 Acceptance Criteria]

**Offer Reference Name:** `INFLUENCER_ANNUAL_FREE`
- This name appears in receipts as `offer_code_ref_name` field
- Used for analytics and tracking which offer was redeemed
- Should be descriptive and unique per campaign

### Marketing Use Case
[Source: Epic 9 - Marketing Use Cases]

**Primary Use Case:** Influencer partnerships
- Provide custom codes to PE community influencers (e.g., u/karlwikman, other community leaders)
- Track which influencers drive subscriptions
- Build credibility through trusted community voices

**Initial Distribution:**
- Generate 50 custom codes for first batch
- Target key Reddit community moderators and contributors
- Use tracking spreadsheet to monitor redemption and ROI

### Future Offer Code Creation
[Source: Epic 9 - Stories Overview]

This is the first offer code configuration, but the system supports:
- Multiple active offers (up to 10 per subscription)
- Different discount amounts (free, 50% off, etc.)
- Different durations (1 month, 3 months, 12 months)
- Different customer eligibility (new only, existing only, both)

Documentation should enable creating additional offers for future campaigns without needing to reference this story.
