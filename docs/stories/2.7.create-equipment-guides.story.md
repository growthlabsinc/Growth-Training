### Data Models
```swift
// Equipment guides will use existing exercise structure
struct PEExercise {
    let id: String  // e.g., "vacuum_pump_guide", "hanger_comparison"
    let title: String
    let description: String
    let category: String  // "equipment" for all guides
    let difficulty: String  // "beginner", "intermediate", "advanced"
    let estimatedDuration: Int  // reading time in minutes
    let equipmentNeeded: [String]  // equipment being discussed
    let steps: [ExerciseStep]  // 8 detailed guide steps
}

struct ExerciseStep {
    let stepNumber: Int  // CRITICAL: Use stepNumber not order
    let title: String  // e.g., "Step 1: Understanding Pump Types"
    let description: String  // CRITICAL: Use description not instruction
    let tips: [String]  // Practical tips for equipment selection
    let cautions: [String]  // Safety warnings and red flags
    let warnings: [String]  // Critical safety information
}
```

### Equipment Guide Requirements
All equipment guides MUST include:
- Clear explanation of equipment types and mechanisms
- Safety considerations prominently featured throughout
- No specific brand endorsements or affiliate links
- Budget tier options (low/medium/high cost alternatives)
- Quality indicators to help users identify safe equipment
- Proper usage protocols and time/intensity limits
- Hygiene and maintenance guidelines
- Warning signs for unsafe or counterfeit equipment
- Medical consultation recommendations before purchase
- Equipment-free alternatives where applicable
[Source: Epic 2 requirements and Story 2.7 acceptance criteria]

### Equipment Categories for Guides
1. **Vacuum Pumps**
   - Air pumps vs water pumps (Bathmate-style)
   - Cylinder sizing and pressure gauges
   - Safety features (pressure release, quality seals)
   - Budget options and quality indicators

2. **Hangers**
   - Vacuum hangers vs strap-based systems
   - Weight progression safety limits
   - Attachment methods and comfort considerations
   - Budget-friendly alternatives

3. **Extenders**
   - Spring-loaded vs vacuum-based mechanisms
   - Comfort accessories and modifications
   - Time commitment and usage protocols
   - Budget considerations and effectiveness

4. **General Equipment Safety**
   - Universal safety checklist for all equipment
   - Red flags for unsafe products
   - Maintenance and hygiene protocols
   - When to discontinue use

NOTE: These are individual GUIDE DOCUMENTS that will be stored in growth_exercises collection with category="equipment". They are educational content, not exercise instructions, designed to help users make informed equipment decisions safely.
[Source: Epic 2 content structure and safety framework]
