### Verification Requirements

Based on Epic 7.6 requirements, the system must:

1. **Automated DOI Checking**
   - Verify each DOI resolves to a valid resource
   - Check HTTP response codes (200 = valid, 404 = broken)
   - Handle redirects appropriately
   - Rate limit requests to avoid API blocks

2. **PubMed Link Validation**
   - Verify PMID exists in PubMed database
   - Check article status (active vs retracted)
   - Update metadata if changed

3. **Quarterly Source Audit**
   - Run verification on all 55 citations every 3 months
   - Generate audit report with status of each citation
   - Flag citations needing attention
   - Track verification history

4. **Update Notifications for Retracted Papers**
   - Monitor PubMed for retraction notices
   - Alert content team when retraction detected
   - Provide alternative source recommendations

5. **Alternative Source Identification**
   - When citation breaks, search for alternative access points
   - Check if article moved to new DOI
   - Look for archived versions (e.g., PubMed Central)

### External API Integration

**DOI Resolution** [Source: DOI.org documentation]
```javascript
async function verifyDOI(doi) {
  const url = `https://doi.org/${doi}`;
  const response = await fetch(url, {
    method: 'HEAD',
    redirect: 'follow'
  });
  return {
    valid: response.ok,
    status: response.status,
    resolvedUrl: response.url
  };
}
```

**PubMed Verification** [Source: PubMed E-utilities API]
```javascript
async function verifyPMID(pmid) {
  const url = `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi?db=pubmed&id=${pmid}&retmode=json`;
  const response = await fetch(url);
  const data = await response.json();

  return {
    valid: !data.error,
    status: data.result?.[pmid]?.pubstatus,
    retracted: data.result?.[pmid]?.attributes?.includes('retracted')
  };
}
```

### Error Handling

**Broken DOI**:
1. Log the broken citation
2. Search CrossRef for alternative DOI
3. Check if article moved to new publisher
4. Flag for manual review if no alternative found

**Retracted Paper**:
1. Mark citation as invalid immediately
2. Alert content team via email/notification
3. Search for replacement studies on same topic
4. Update article with new citation

**Rate Limit Exceeded**:
1. Implement exponential backoff
2. Pause script and resume later
3. Don't mark citations as broken if verification failed due to rate limiting
