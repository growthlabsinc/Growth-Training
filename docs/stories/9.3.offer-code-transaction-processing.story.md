## Dev Notes

### SimplifiedPurchaseManager Transaction Observer
[Source: Growth/Core/Services/SimplifiedPurchaseManager.swift]

**Current Transaction Observation Pattern:**
```swift
private func observeTransactionUpdates() -> Task<Void, Never> {
    Task.detached {
        for await result in Transaction.updates {
            await self.handle(transactionResult: result)
        }
    }
}
```

**Transaction Verification:**
- Uses StoreKit 2 `Transaction.updates` async sequence
- Verifies transactions via `verifyTransaction(_:)` method
- Updates `purchasedProductIDs` set
- Calls `entitlementManager.updateFromPurchasedProducts(purchasedProductIDs)`

**Where to Add Offer Code Detection:**
In the transaction handling logic, check for `Transaction.offerID` property (StoreKit 2 API).

### StoreKit 2 Offer Code Detection
[Source: Epic 9 - Apple Documentation Reference]

**StoreKit 2 Transaction Properties:**
```swift
extension Transaction {
    var offerID: String? // Available in iOS 16.0+
    // Returns the offer identifier if this transaction came from an offer code
}
```

**Detection Pattern:**
```swift
func handle(transactionResult: VerificationResult<Transaction>) async {
    guard case .verified(let transaction) = transactionResult else { return }

    // Existing purchase logic...

    // NEW: Detect offer code
    if let offerID = transaction.offerID {
        print("🎟️ Offer code redemption detected: \(offerID)")
        await handleOfferCodeTransaction(offerID: offerID, transaction: transaction)
    }

    await transaction.finish()
}
```

**Current App Group Usage:**

**New Storage Keys:**
- `com.growthlabs.lastOfferCodeRedeemed` - String (offer ID)
- `com.growthlabs.lastOfferCodeTimestamp` - Double (Unix timestamp)
- `com.growthlabs.lastOfferCodeUserId` - String (Firebase Auth UID)

**Storage Pattern:**
```swift
func storeOfferCodeRedemption(offerID: String, timestamp: Date) {
    Self.userDefaults.set(offerID, forKey: "com.growthlabs.lastOfferCodeRedeemed")
    Self.userDefaults.set(timestamp.timeIntervalSince1970, forKey: "com.growthlabs.lastOfferCodeTimestamp")
    if let userId = Auth.auth().currentUser?.uid {
        Self.userDefaults.set(userId, forKey: "com.growthlabs.lastOfferCodeUserId")
    }
}
```

### Firebase Functions Integration
[Source: functions/subscriptionLifecycle.js, functions/index.js]

**Existing Subscription Functions:**
- File: `functions/subscriptionLifecycle.js`
- Exports functions for subscription management
- Already integrated with Firebase Auth for user context

**New Function to Add:**
```javascript
exports.logOfferCodeRedemption = functions
  .region('us-central1')
  .https.onCall(async (data, context) => {
    // Verify authentication
    if (!context.auth) {
      throw new functions.https.HttpsError('unauthenticated', 'User must be authenticated');
    }

    const { offerCodeRef, timestamp, platform, subscriptionProductId } = data;
    const userId = context.auth.uid;

    // Store in Firestore
    await admin.firestore()
      .collection('offer_code_redemptions')
      .doc(userId)
      .collection('redemptions')
      .doc(timestamp.toString())
      .set({
        offerCodeRef,
        userId,
        timestamp,
        platform,
        subscriptionProductId,
        createdAt: admin.firestore.FieldValue.serverTimestamp()
      });

    // Log analytics event
    await admin.analytics().logEvent('offer_code_attributed_subscription', {
      offer_code_ref: offerCodeRef,
      user_id: userId,
      platform
    });

    return { success: true };
  });
```

**Registration in index.js:**
```javascript
const subscriptionLifecycle = require('./subscriptionLifecycle');
exports.logOfferCodeRedemption = subscriptionLifecycle.logOfferCodeRedemption;
```

### Firebase Analytics Events
[Source: Epic 9 - Analytics & Tracking]

**Event to Track:**
- Event name: `offer_code_attributed_subscription`
- Parameters:
  - `offer_code_ref` (String) - The offer reference name from App Store Connect
  - `user_id` (String) - Firebase Auth UID
  - `timestamp` (Number) - Unix timestamp of redemption
  - `platform` (String) - "iOS" or "Android"
  - `subscription_product_id` (String) - Which subscription was redeemed

**Tracking from iOS:**
```swift
Analytics.logEvent("offer_code_attributed_subscription", parameters: [
    "offer_code_ref": offerID,
    "user_id": Auth.auth().currentUser?.uid ?? "unknown",
    "timestamp": Date().timeIntervalSince1970,
    "platform": "iOS",
    "subscription_product_id": transaction.productID
])
```

### Security Considerations
[Source: Epic 9 - Risk Mitigation]

**Validation Handled by Apple:**
- Offer code validation already done by Apple before transaction
- Receipt verification happens via StoreKit 2 automatic verification
- No custom validation needed in app

**Firebase Function Security:**
- Require authentication: `if (!context.auth) throw error`
- Use authenticated user ID from context, not from client data
- Firestore security rules: Users can only write to their own redemption docs

- Only store offer ID, not the actual code
- User ID from Firebase Auth (already authenticated)
- No PII beyond what's already in auth system
