### App Group Architecture

**What is an App Group?**
App Groups enable data sharing between the main app and widget extension. The Growth Training app uses App Groups to share:
- Timer state between app and Live Activity widget
- Subscription entitlement data
- User preferences and settings
- Analytics data

**Critical Files Using App Group**:
1. **AppGroupConstants.swift** - Defines shared group identifier
2. **SimplifiedEntitlementManager.swift** - Accesses subscription data via shared UserDefaults
3. **SimplifiedEntitlementManagerWithTrial.swift** - Accesses trial/subscription state
4. **FeatureAccess.swift** - Checks premium features via shared data
5. **PaywallAnalyticsService.swift** - Stores analytics data in shared container

**How App Groups Work**:
```swift
// Current implementation
static let identifier = "group.com.growthlabs.growthmethod"
let userDefaults = UserDefaults(suiteName: identifier)

// Widget extension and main app both access same UserDefaults via this suite name
// Changes must be synchronized across all .entitlements files
```

### Bundle ID Change Impact

**Systems Affected by Bundle ID Changes**:
1. **App Signing** - Provisioning profiles tied to bundle ID
2. **App Groups** - Shared data container between app and extensions
3. **Keychain** - Secure storage tied to bundle ID
4. **Push Notifications** - APNS certificates tied to bundle ID
5. **Firebase** - GoogleService-Info.plist tied to bundle ID
6. **App Store Connect** - App record tied to bundle ID
7. **StoreKit** - In-app purchase products tied to bundle ID

**Migration Considerations**:
- Changing bundle ID creates a NEW app in App Store (cannot update existing)
- User data in keychain may need migration
- Shared UserDefaults data may need migration
- Push notification tokens will be invalidated

**NOTE**: Based on Epic 5 context, this appears to be a new app deployment (Growth Training) separate from the original Angion Method app. Bundle ID change is intentional for new app identity.

[Source: Apple Developer Documentation, Epic 5 migration strategy]
