# Story 11.2: Session Log CSV Export

## Status
**Complete**

## Story
**As a** Growth Training user who wants to contribute to PE research,
**I want** to export my anonymized session logs as a CSV file compatible with GrowthTrack,
**so that** I can share my training data with the research community while protecting my privacy.

## Acceptance Criteria
1. Service exports all SessionLog entries for current user in GrowthTrack CSV format
2. All PII is stripped: userId, userNotes, methodId excluded from export
3. Anonymous ID from AnonymizationService (Story 11.1) is included in each row
4. Measurements converted from inches to millimeters (rounded to nearest mm)
5. CSV includes: anonymous_id, date, category, duration_minutes, pre_bpel_mm, pre_bpfsl_mm, pre_mseg_mm, post_bpel_mm, post_bpfsl_mm, post_mseg_mm
6. Sessions without pre/post measurements are excluded from export
7. Date format is YYYY-MM-DD (no time component)
8. File is saved via iOS share sheet with naming: `growth-training-sessions-YYYY-MM-DD.csv`
9. Missing measurement values handled gracefully (empty string in CSV)
10. Service provides progress updates during export for UX feedback

### Fetching SessionLogs from Firestore
[Source: Growth/Core/Services/SessionService.swift, FirestoreService.swift]

**Pattern to follow:**
```swift
func fetchAllSessionLogs(userId: String) async throws -> [SessionLog] {
    let db = Firestore.firestore()
    let snapshot = try await db.collection("sessionLogs")
        .whereField("userId", isEqualTo: userId)
        .order(by: "startTime", descending: true)
        .getDocuments()

    return snapshot.documents.compactMap { doc in
        try? doc.data(as: SessionLog.self)
    }
}
```

**Note:** Use async/await pattern (modern Swift), not completion handlers

### Measurement Conversion
[Source: Epic 11 PRD - Measurement Unit Conversion]

**Formula:** inches × 25.4 = millimeters (round to nearest integer)

**Examples:**
- 6.0" → 6.0 × 25.4 = 152.4 → round = 152mm
- 6.5" → 6.5 × 25.4 = 165.1 → round = 165mm
- 4.5" → 4.5 × 25.4 = 114.3 → round = 114mm

**Swift Implementation:**
```swift
private func convertToMillimeters(_ inches: Double?) -> String {
    guard let inches = inches else { return "" }
    return "\(Int(round(inches * 25.4)))"
}
```

### Privacy Guarantee Implementation
[Source: Epic 11 PRD - Privacy & Ethics]

**Critical: PII Stripping Checklist**

❌ **NEVER include in CSV:**
- `userId` (Firebase Auth UID)
- `userNotes` (free text could contain identifying info)
- `methodId` (routine ID could be identifying pattern)
- `sessionIndex` (could identify user's training pattern)
- `moodBefore/moodAfter` (unnecessary, could be fingerprinting)
- `intensity` (unnecessary for GrowthTrack)
- `variation` (free text, could be identifying)
- `startTime` time component (only date needed)

✅ **Safe to include:**
- `anonymousId` (randomized, from Story 11.1)
- `date` (YYYY-MM-DD only, no time)
- `category` (generic: lengthwork/girthwork/hybrid)
- `duration` (integer minutes)
- `preMeasurements[.bpel, .bpfsl, .mseg]` (numeric only)
- `postMeasurements[.bpel, .bpfsl, .mseg]` (numeric only)

### Error Handling Strategy
[Source: Existing export services pattern]

```swift
enum CSVExportError: LocalizedError {
    case noUser
    case noSessionsFound
    case exportFailed(String)

    var errorDescription: String? {
        switch self {
        case .noUser:
            return "No user logged in. Please sign in to export data."
        case .noSessionsFound:
            return "No session logs found to export."
        case .exportFailed(let reason):
            return "Export failed: \(reason)"
        }
    }
}
```

**Throw errors for:**
- User not authenticated (Firebase Auth check)
- No sessions found (empty query result)
- File write failures

**Don't throw for:**
- Individual session missing measurements (skip row)
- Empty optional fields (use empty string)
