### Onboarding Flow Steps (10 total)

```swift
enum OnboardingStep: Int, CaseIterable {
    case welcome = 0                    // Welcome screen with value props
    case themeSelection                 // Color theme preference
    case disclaimer                     // Medical safety disclaimer
    case privacy                        // Privacy & terms acceptance
    case initialAssessment              // Experience level selection
    case paywall                        // Premium subscription offer
    case routineGoalSelection           // Goal and routine selection
    case notificationPermissions        // Push notification opt-in
    case profileSetup                   // User profile creation
    case celebration                    // Completion/get started
}
```

[Source: Growth/Features/Onboarding/Models/OnboardingStep.swift]

**Flow Logic**:
- Progress indicator shows current step out of 10
- Back navigation supported (calls `viewModel.regress()`)
- Forward navigation with `viewModel.advance()`
- Paywall can be skipped if `FeatureFlags.showPaywallInOnboarding` is false
- Completion saves user preferences to Firestore via `OnboardingViewModel.completeOnboarding()`

[Source: Growth/Features/Onboarding/ViewModels/OnboardingViewModel.swift]
