## Story

**I want** to redeem offer codes directly within the app,

### Apple Offer Code Redemption APIs
[Source: Epic 9 - Apple Documentation Reference]

**iOS 16+ Primary API:**
```swift
.offerCodeRedemption(isPresented: $showingRedemption) { result in
    switch result {
    case .success:
        // Code redeemed successfully
        // App receives transaction automatically via transaction observer
    case .failure(let error):
        // Handle error (invalid code, expired, etc.)
        print("Redemption failed: \(error)")
    }
}
```

**iOS 14-15 Fallback API:**
```swift
import StoreKit

SKPaymentQueue.default().presentCodeRedemptionSheet()
// No completion handler available
// Must rely on transaction observer to detect redemption
```

**Important Notes:**
- Apple's sheet handles all validation (code format, expiration, eligibility)
- App automatically receives transaction when code is successfully redeemed
- No need to manually validate codes or check format
- Sheet presents modally and dismisses automatically

**Redemption Flow:**
1. User taps "Redeem Offer Code" button

4. If valid, Apple processes redemption
5. App receives transaction via existing transaction observer
6. SimplifiedEntitlementManagerWithTrial detects transaction (Story 9.3 implementation)
7. Entitlement flags update (`hasPremium` = true)
8. Paywall auto-dismisses (already implemented in onChange handler line 93-97)
