### Article Structure
1. **YAML Frontmatter** (metadata)
2. **Title** (H1)
3. **Introduction** (200-300 words)
4. **Main Content Sections** (H2 headers, 3-5 sections, 1000-2000 words total)
5. **Key Takeaways** (bullet list, 100-200 words)
6. **Medical Disclaimer** (required standard text)
7. **References** (APA 7th edition, all sources cited)
