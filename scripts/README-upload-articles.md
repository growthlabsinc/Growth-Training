# Educational Articles Upload Script

This document explains how to upload educational articles to Firestore using the `upload-educational-articles.js` script.

## Overview

The upload script batch-uploads 8 educational articles from `scripts/reddit-scraper/generated_articles/` to the Firestore `educational_resources` collection.

## Prerequisites

1. **Firebase Admin SDK installed** (already installed in project)
2. **Google Cloud authentication** set up
3. **Firebase project**: `growth-training-app`

## Usage

### Initial Upload

```bash
# From project root
node scripts/upload-educational-articles.js
```

### Authentication

The script uses **Application Default Credentials**. If you encounter auth errors:

```bash
# Re-authenticate with Google Cloud
gcloud auth application-default login

# Verify authentication
gcloud auth application-default print-access-token
```

### Environment Variables

- `FIREBASE_PROJECT`: Override default project (defaults to `growth-training-app`)
- `GOOGLE_APPLICATION_CREDENTIALS`: Path to service account key (optional)

Example with custom project:

```bash
FIREBASE_PROJECT=your-project-id node scripts/upload-educational-articles.js
```

- **Total citations**: 40 (5 per article)

## Re-uploading / Updating Articles

### Option 1: Delete and Re-upload

Use the Firestore console to manually delete all documents from `educational_resources`, then re-run the script.

### Option 2: Rollback Script

Create a rollback script to delete all articles:

```javascript
// rollback-articles.js
const admin = require('firebase-admin');
admin.initializeApp({ projectId: 'growth-training-app' });
const db = admin.firestore();

async function deleteAll() {
  const snapshot = await db.collection('educational_resources').get();
  const batch = db.batch();
  snapshot.docs.forEach(doc => batch.delete(doc.ref));
  await batch.commit();
  console.log(`Deleted ${snapshot.size} articles`);
}

deleteAll();
```

Then run:

```bash
node rollback-articles.js
node scripts/upload-educational-articles.js
```

## Troubleshooting

### Authentication Errors

**Error**: `invalid_grant` or `invalid_rapt`

**Solution**:
```bash
# Clear cached credentials
rm -rf ~/.config/gcloud/application_default_credentials.json

# Re-authenticate
gcloud auth application-default login
```

### Wrong Project

**Error**: Articles uploaded to wrong Firebase project

**Solution**: Verify project with:
```bash
gcloud config get-value project
```

Set correct project:
```bash
gcloud config set project growth-training-app
```

### Missing JSON Files

**Error**: `File not found: scripts/reddit-scraper/generated_articles/*.json`

**Solution**: Verify files exist:
```bash
ls -lh scripts/reddit-scraper/generated_articles/*.json
```

If missing, regenerate articles from Story 7.2.

## Security Rules

The Firestore security rules for `educational_resources`:

```
match /educational_resources/{resourceId} {
  allow read: if request.auth != null;  // Authenticated users only
  allow write: if false;                 // Admin-only (server-side)
}
```

- **Read**: Requires authentication (iOS app users)
- **Write**: Denied (server-side upload scripts only)
